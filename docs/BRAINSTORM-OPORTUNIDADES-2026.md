### 🔴 PROBLEMA #1: Lentes Campanha é PÉSSIMA

**Dados (rankings relativos — valores absolutos em revalidação):**
- Campanha menos eficiente (4.5x pior que Urgências)
- CTR: 1.63% (pior de todas)
- Spend mensal total ads: ~R$ 9.000 (Lentes recebe parcela significativa com baixo retorno)
- Comparação: Urgências é 4.5x mais eficiente

**Hipóteses:**
1. **Message match ruim?** Ad copy genérico ("estética dental") vs. LP headline não specific?
2. **Landing page é fraca?** Não comunica "Test Drive do Sorriso" (unique differentiator)
3. **Público-alvo errado?** Keywords muito genéricas ("lentes de contato dental")?
4. **Negative keywords faltando?** Competindo com keywords irrelevantes?
5. **Quality Score baixo?** CTR baixo causa QS baixo = CPC mais caro
6. **Medo de precço?** Lentes é serviço premium, paciente quer saber valor?

**Ações Recomendadas (QUICK WINS):**
- [ ] **A/B test:** Nova LP de Lentes com foco em "Test Drive do Sorriso" + "visualiza antes de começar"
- [ ] **Copy rewrite:** Ad copy com message match: "Veja seu sorriso em 3D antes de fazer"
- [ ] **Keyword audit:** Pausar keywords muito genéricas, focar em "lentes de porcelana" (mais specifica)
- [ ] **Negative keywords:** Adicionar "moda", "cor", "contato" (para não competir com contact lenses reais)
- [ ] **Quality Score:** Melhorar link relevância → expected CTR deve subir
- **Timeline:** 2 semanas implementação, 2 semanas teste, 2 semanas análise = **6 semanas até validação**
- **Revenue impact esperado:** Reduzir cost/conv 50% = +2-4 pacientes/mês (ticket R$ 800-1.000 cada)

### 📱 OPORTUNIDADE #6: Mobile Optimization

**Current issue:**
- FCP 3.1s (should be <2.5s)
- LCP 3.6s (should be <2.0s)
- Mobile dominates traffic — means EVERY ms counts

**Root causes (hypothesis):**
1. Hero image não otimizada (likely culprit)

- [ ] **Font optimization:** Preload critical fonts, use `font-display: swap` (já há!)
- [ ] **Lazy load below-fold images:** Implement Intersection Observer
- [ ] **CSS audit:** Remove unused Tailwind? (unlikely issue, mas checar)
- [ ] **Lighthouse audit:** Identify specific bottlenecks
- **Timeline:** 1-2 weeks
- **Revenue impact:** Faster mobile = better UX = +3-5% CTR = **R$ 10-20k/mês**
