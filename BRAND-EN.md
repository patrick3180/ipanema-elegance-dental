## 2. Title "Dr." — English Convention

- **Always** use "Dr." in English content — never "Dra."
- In American English, "Dr." is gender-neutral and used for both male and female doctors/dentists.
- "Dra." is a Portuguese/Spanish convention and should **only** appear in PT content.
- Correct (EN): "Dr. Carla Christoph"
- Incorrect (EN): "Dra. Carla Christoph" / "Doctor Carla Christoph"
- Acceptable in running text: "your dentist" / "the specialist"
- **Note:** The Portuguese site (BRAND.md) continues to use "Dra." as is standard in Brazilian Portuguese.

## 3. Tone of Voice in English

The English tone is identical in spirit to the Portuguese BRAND.md but adapted for an international audience:

| Characteristic | How It Manifests |
|---------------|-----------------|
| **Confident** | Affirmative sentences, no hedging. "Each implant is planned digitally." (not "We try to plan...") |
| **Direct** | Gets to the point. No empty introductory paragraphs. |
| **Warm** | Acknowledges legitimate concerns. "Root canals have an unfair reputation." |
| **Specific** | Names real technologies, materials, processes. Never generic adjectives. |
| **Unhurried** | The text breathes. Short paragraphs. Space between ideas. |
| **Respectful** | Never speaks poorly of competitors, other dentists, or previous treatments. |

### Additional English-Specific Guidance

- **Avoid overly clinical language** when a simple word exists: "tooth" over "dentition", "gum" over "gingiva" (unless medical precision required)
- **No Britishisms**: Use American English spelling and conventions (e.g., "color" not "colour")
- **Avoid fake urgency**: "Book now before it's too late" → Never.
- **CRO number context**: Always add "(Brazilian Dental Board)" on first mention per page: "CRO-RJ 27.509 (Brazilian Dental Board)"

## 4. Banned Words & Phrases (English)

All bans from BRAND.md Section 5 apply. Additional English-specific bans:

| ❌ Banned | ✅ Replacement |
|----------|---------------|
| "perfect smile" | remove, or "a smile that feels like yours" |
| "transform your smile" | remove, or "restore confidence in your smile" |
| "premium" | never use — show, don't tell |
| "world-class" | never use — implies ranking that doesn't exist |
| "excellence" | remove completely |
| "state-of-the-art" | name the actual technology: "iTero Element 5D scanner" |
| "pain-free" / "painless" | "comfortable" or describe: "under local anesthesia" |
| "best dentist in Rio" | never use — cannot be substantiated |
| "Hollywood smile" | never use — implies fake, standardized result |
| "affordable" / "cheap" | never use — positioning conflicts |
| "free consultation" | **ABSOLUTELY NEVER** — consultations are never free |
| "guaranteed results" | never use — CRO/CFO prohibits guarantees |
| "before and after" | never reference — photos are prohibited by CRO |
| "cutting-edge" | name the specific technology instead |
| "luxury" / "luxurious" | never use — show, don't tell |
| "exclusive" (standalone) | acceptable only with a specific noun: "our exclusive Smile Test Drive" |
| "100% natural" | "natural to the point of going unnoticed" |

## 7. CRO/CFO Compliance (English Context)

These rules are **non-negotiable** and apply to all English content:

| Rule | Application |
|------|-------------|
| **Never mention prices** | Anywhere — site, LP, ads, public WhatsApp. Prohibited by CRO. |
| **Never use before/after photos** | Even if real. Brazilian regulation prohibits in digital marketing. |
| **Never use procedure photos** | Open mouths, instruments, blood — prohibited and counterproductive. |
| **Never criticize other dentists** | Not even implicitly ("unlike other clinics..."). |
| **Never guarantee results** | "We guarantee a perfect smile" is prohibited. Use realistic expectation language. |
| **Never use misleading terms** | "Painless", "risk-free", "100% safe" — avoid absolutes. |
| **CRO always visible** | CRO-RJ 27.509 must appear on marketing materials and site pages. |
| **Never offer free consultations** | Consultations are NEVER free. This is a firm business rule. |
